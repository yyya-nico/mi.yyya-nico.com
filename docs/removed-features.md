# このフォークで廃止した機能

ウィジェット、メッセージ（ローカルチャット）、みつける、お知らせ、チャンネル、UI切り替え・デッキ、二次元コード（二段階認証の登録画面を除く）、リスト、アンテナ、お気に入り、ページ、Play、ギャラリー、実績、Misskey Games、スクラッチパッド、クッキークリッカー、アバターデコレーション、AiScriptを廃止しています。AiScript製プラグインのインストールと保存済みプラグインの実行も停止します。

専用画面と129個のREST API登録を削除し、API仕様・SDKも更新しています。削除したAPIはGET・POSTとも404になります。関連するWebSocket購読、main/broadcastイベント、SSRの機能専用データ配信も停止します。

既存DBと過去のmigrationは保持します。ユーザー情報の装飾・実績・固定ページ・未読チャット等は空、null、false等の互換値を返します。過去のチャンネル投稿はチャンネル情報を表示せず、新たなチャンネル投稿・返信・予約投稿は禁止します。

## 残している共用API

以下は廃止機能以外にも使用するため、API自体を削除していません。

| API | 残す理由・制限 |
| --- | --- |
| `i/registry/*` | 通常設定、テーマ、設定バックアップの保存・同期に必要。過去のウィジェット・デッキ・プラグイン設定が保存されていても実行・表示しない。 |
| `i/update` | プロフィール、プライバシー、通知設定に必要。装飾は空配列、固定ページはnull、チャット範囲はnoneのみ。通知のリスト指定は禁止。お知らせメール設定はfalseに固定。 |
| `notes/create`、`notes/drafts/*` | 通常投稿・下書き・予約投稿に必要。チャンネル指定は禁止し、過去のチャンネル投稿への返信もサービスで拒否する。 |
| `notes/search`、`notes/featured`、`users`、`pinned-users`、`roles/*`、`hashtags/*` | 検索、訪問者向けタイムライン、アカウント初期設定、インスタンス情報、ロール・タグ表示で共用。「みつける」画面と専用の`users/recommendation`は削除。チャンネル指定検索・ランキングは禁止。 |
| `notes/state` | スレッドミュート状態の取得に必要。お気に入り状態は常にfalse。 |
| `i/2fa/*` | 二段階認証の登録・解除に必要。登録画面の二次元コード表示・設定用URIの登録は維持。画像透かし・フレームの二次元コード生成は停止。 |
| `app/*`、`auth/*`、`miauth/*`、OAuth関連 | 通常の外部クライアント認証に必要。廃止機能の権限は選択肢から除外。 |
| `fetch-external-resources` | テーマのインストールにも使用。プラグインとしてのインストール・実行は不可。 |

通常の宛先指定ノート（`visibility: specified`）は投稿機能・連合互換性のため維持します。廃止した「メッセージ」は`chat/*`のローカルチャットです。ノート・クリップ・フォロー等の通常APIや、そのWebSocket配信は維持します。

画像のクロップ・エフェクト・ウォーターマーク・フレームと、その設定・プリセットの適用を廃止しています。画像・動画の圧縮とクリップは維持します。RSS取得API（`fetch-rss`）、RSSステータスバー、ユーザーのRSS・Atom・JSONフィード配信も廃止しています。
